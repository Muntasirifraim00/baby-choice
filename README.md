# Pixel Perfect Mockup

এই screen টা আমাকে 100% same to same বানিয়ে দাও। এই ছবিগুলো যেভাবে আছে সেভাবেই তুমি বানাবে। লেখা যেমন আছে তেমনি বানাবে। প্রতিটা button, প্রতিটা category, প্রতিটা ছবি, প্রতিটা অংশ, প্রতিটা অংশের size same হতে হবে এবং এটা যেই একটা mobile view এর ভিতরে আছে ঠিক সেরকমই mobile view এর ভিতরেই থাকতে হবে। এটাকে সম্পূর্ণ এভাবেই বানিয়ে দেবে আমার জন্য। ছবিগুলো সহ এবং আপাতত অন্য কোন functionality কাজ করতে হবে না। শুধু placeholder হিসেবে বসিয়ে দিলেই হবে। আপাতত এটা বানাও। এর পরবর্তীতে যখন আমি single product page বা category page বানাতে বলব তখন বানাবে। আপাতত বানাতে হবে না। আপাতত এটা demo হিসেবে বানাও। প্রথম এই screen টা।
